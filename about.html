About Online PDF Editor

Online PDF Editor is a free browser-based tool for making selected changes to PDF documents and adding visual annotations. It is designed for people who need to make quick document edits without installing desktop software or creating an account.

Available features

  • Open PDF files from your device.
  • Replace detected selectable text using an inline editor.
  • Add new text notes to PDF pages.
  • Draw, highlight and add rectangular marks.
  • Place visual white covers over page areas.
  • Download or print the resulting PDF.

How PDF processing works

The selected PDF is read and processed in your browser. The page uses PDF.js to render pages and pdf-lib to create the exported document. The selected document is not uploaded to this website's file-storage server. Your browser loads these software libraries from cdnjs.

Current limitations

Text replacement depends on the PDF containing selectable text that the editor can detect. Scanned documents that contain only images do not provide selectable text unless OCR is performed separately. The current export creates page images in a new PDF, so searchable text, links, forms, accessibility structure and some original PDF features may not be preserved. Whiteout is only a visual cover and is not secure redaction.
