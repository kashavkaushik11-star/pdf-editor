About Online PDF Editor

Online PDF Editor is a lightweight browser-based tool for adding visual annotations to PDF documents. It is designed for people who need to mark up a document without installing a desktop application or creating an account.

What the tool currently does

  • Opens a PDF selected from your device.
  • Lets you draw marks on PDF pages.
  • Lets you add short text notes.
  • Lets you highlight a selected area.
  • Lets you place a white visual cover over an area.
  • Creates a downloadable PDF from the annotated page images.

How files are processed

The selected PDF is read and processed in your browser. This website does not provide a PDF upload or cloud-storage service. The page loads PDF.js and pdf-lib software libraries from cdnjs to render and create PDF content.

Current limitations

The current version is an annotation tool, not a full PDF text editor. It does not edit existing selectable text. Exported pages are image-based, so text search, text selection, hyperlinks, form fields, accessibility structure and other original PDF features may not be retained. Whiteout is a visual cover and is not secure redaction.
