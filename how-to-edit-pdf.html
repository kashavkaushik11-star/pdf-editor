How to Edit a PDF Online

Follow this guide to edit detected selectable text and add annotations to a PDF using Online PDF Editor. The tool runs in your browser and does not require an account.

1. Open your PDF file

Open the free online PDF editor, choose Open PDF and select a file from your device. You can also drag a PDF into the editor area.

2. Replace selectable text

Choose Edit Text and click a text item on the PDF page. If the editor detects the text, an inline text box appears so you can change its wording. This works with selectable text in the PDF, not text that exists only inside a scanned page image. Scanned PDFs need OCR before their text can be selected.

3. Add notes and annotations

  • Text: click the page to add a new text note.
  • Draw: draw freehand marks on the page.
  • Highlight: drag over an area to add a highlight.
  • Box: draw a rectangular outline.
  • Whiteout: place a visual cover over an area. This is not secure redaction.

4. Download or print the result

Choose Download to create an edited PDF, or use Print to print the result. Open the exported document and check every page before sharing it.

Important export limitations

The current export creates page images in a new PDF. As a result, the exported text may not remain searchable or selectable, and original links, forms, accessibility structure and other PDF features may not be retained. Keep your original PDF as a backup.

Privacy and file handling

The selected PDF is processed in your browser and is not uploaded to this website's file-storage server. The page loads PDF.js and pdf-lib libraries from cdnjs. Read the Privacy Information for more details.
