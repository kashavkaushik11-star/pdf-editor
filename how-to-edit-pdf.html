How to Edit and Annotate a PDF Online

This guide explains how to add visual notes and marks to a PDF using the free Online PDF Editor. The tool runs in a modern web browser and does not require an account.

Step 1: Open your PDF file

Open the Online PDF Editor, choose Open PDF and select a PDF file stored on your device. Wait for the pages to appear in the editor.

Step 2: Choose an annotation tool

  • Draw: draw a line or mark on a page.
  • Add Text: click the page and enter a short text note.
  • Highlight: drag across an area to add a translucent highlight.
  • Whiteout: drag over an area to cover it visually with white.

Step 3: Download the result

Choose Download PDF. Your browser creates the output file and saves it to your device. Open the downloaded file to check that the annotations appear as expected.

Important limitations

This editor adds visual annotations; it does not directly modify existing selectable PDF text. Exported pages are image-based, so searchable text, links, forms and accessibility information may not be retained. Whiteout is not secure redaction and must not be used to conceal sensitive information permanently.

Privacy

The selected PDF is processed in your browser rather than uploaded to this website's server. The website loads its PDF software libraries from cdnjs. Read the Privacy Information for details.
