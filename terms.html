Use of the tool

Online PDF Editor provides browser-based visual annotation features for convenience. You are responsible for ensuring that you have the right to use and modify any document you open.

Tool limitations

The current tool adds visual annotations and exports page images into a new PDF. It does not directly edit existing selectable PDF text. Original hyperlinks, forms, selectable text, accessibility structure and other PDF features may not be retained.

No secure redaction

The Whiteout tool places a visual white cover over page content. It does not securely erase underlying text, images or metadata. Do not rely on it to remove confidential or sensitive information.

Availability

The website is provided as-is. We do not guarantee uninterrupted availability, compatibility with every PDF, or preservation of every feature in the original document. Keep a separate copy of your original file.

The website uses PDF.js and pdf-lib libraries loaded from cdnjs. Their availability may affect the editor.
