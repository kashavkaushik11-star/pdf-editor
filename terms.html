Use of the tool

Online PDF Editor provides browser-based PDF text replacement and visual annotation features for convenience. You are responsible for ensuring that you have the right to access and modify any document you open.

Technical limitations

Text replacement is available only for selectable PDF text that the editor can detect. Scanned image-only PDFs require OCR before text can be selected. The exported PDF is created from page images; searchable text, links, forms, accessibility structure and other original PDF features may not be retained. Keep a separate copy of the original document.

Whiteout is not secure redaction

The Whiteout tool places a visual cover over page content. It does not securely erase underlying text, images or metadata. Do not rely on it to permanently remove confidential or sensitive information.

Availability and third-party software

The website is provided as-is. We do not guarantee uninterrupted availability or compatibility with every PDF. The editor loads PDF.js and pdf-lib libraries from cdnjs, and their availability may affect the tool.
